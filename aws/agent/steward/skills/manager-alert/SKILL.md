# Writing the manager alert

The manager reads it on a phone, possibly at night. Make the first line enough to act on.

1. **First line**: what, where, how bad. "Buoy 3 (east end) is reading 19.6 °C, 9 °C above the rest of the lake."
2. **Why it isn't natural**, in one or two sentences with numbers: river, weather, other buoys.
3. **Likely source**, with confidence: name the facility and its distance only if the evidence points there; otherwise say "unknown".
4. **What to do now**: a specific next step (inspect buoy 3 and the outfall at …, call NJDEP hotline 1-877-927-6337 if a discharge is visible, collect a water sample).
5. Under 120 words. No markdown, no jargon like NDTI.
